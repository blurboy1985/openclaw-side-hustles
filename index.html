Common Mistakes

  • Using Claude Opus for everything → $160+/month surprise
  • Expecting immediate perfection (agents make mistakes initially)
  • Underestimating iteration time (2-3 weeks of optimization)
  • Not monitoring API costs daily in first week

🔐 Security Best Practices

✅ DO

  • Only install skills from trusted sources
  • Review skill code before installing
  • Run on dedicated machine or VM
  • Use separate API keys (not primary accounts)
  • Enable security scanning

❌ DON'T

  • Install skills with >100 downloads and no reviews
  • Give file system access to untrusted skills
  • Use production API keys in testing
  • Expose gateway to public internet without hardening
  • Ignore security warnings from community
